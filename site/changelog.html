Version history

Every release of SS+. Download the latest from GitHub Releases.

1.4.0 25 August 2026

  • Google Drive: reinstalling or signing in again now reuses your existing SS+ folder — no more duplicate folders.
  • Launch at login is on by default for new installs (Settings → General to change).
  • Check for updates: "You're up to date" / new-version dialog with a Version history button; automatic daily check (can be turned off).
  • Website with privacy policy, terms and this page; links after Google sign-in and in Settings.
  • App version shown in the menu-bar menu and in Settings → About.

1.3.0 25 August 2026

  • Google Drive upload with your own account (drive.file scope): SS+ folder, "anyone with the link" sharing, link copied to clipboard, Drive chips on the preview card.
  • Optional video upload to Drive (off by default) using resumable uploads.
  • Uninstall / reset permissions option for a clean reinstall.
  • Branded "Google Drive connected" page after sign-in.
  • Settings redesigned: native title-bar tabs, compact two-column rows, About panel.
  • Stable code-signing identity so the Screen Recording permission survives updates.
  • Editor after capture is now off by default; new Pro activation code.

1.2.0 25 August 2026

  • English interface option (System / Türkçe / English), applied instantly.
  • Taller Settings window so tabs fit without scrolling.

1.1.0 25 August 2026

  • Recording is finalized on quit and on stream interruption — no more unplayable files.
  • The record shortcut and menu item now stop a recording; broken files are never reported as saved.
  • Clipboard history became opt-in with an "clear on quit" option; encoding moved off the main thread.
  • New default shortcuts ⌃⌘– / ⌃⇧⌘– (plain ⌘– hijacked "Zoom Out" everywhere); safer shortcut recorder.
  • Video settings exposed: container, codec, bit rate, system audio, cursor.
  • Release version is written into the app bundle.

1.0.0 24 August 2026

  • First release: island interface, area/window/full-screen capture, in-place annotation editor, video recording, preview card, clipboard strip, Pro (OCR, 60 fps, system audio).
